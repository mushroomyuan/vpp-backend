# 数据库配置分层重构

## 目标结构

- **公共字段**：`Host / Port / User / Password / DBName` — 所有关系型 DB 共用
- **差异字段**：`Params map[string]string` — 由各具体 infra 包自行解析（postgres 读 `sslmode`/`TimeZone`，mysql 读 `charset`/`parseTime`）
- **DSN escape hatch**：`DSN string` 可选，若非空则各 infra 包直接使用，跳过字段拼装

## 文件变更

### 1. [`infrastructure/db/config.go`](internal/resource/infrastructure/db/config.go)

替换当前 `DSN string` 为结构化字段：

```go
type Config struct {
    Driver   string
    Host     string
    Port     int
    User     string
    Password string
    DBName   string
    Params   map[string]string // driver-specific: sslmode/TimeZone for pg; charset/parseTime for mysql
    DSN      string            // optional override; if non-empty, infra packages use it directly

    MaxOpenConns           int
    MaxIdleConns           int
    ConnMaxLifetimeSeconds int
    ConnMaxIdleTimeSeconds int
}
```

### 2. [`options/options.go`](internal/resource/options/options.go)

`DatabaseOptions` 对齐同样结构（公共字段 + `Params` + `DSN`）：

```go
type DatabaseOptions struct {
    Driver   string            `mapstructure:"driver"`
    Host     string            `mapstructure:"host"`
    Port     int               `mapstructure:"port"`
    User     string            `mapstructure:"user"`
    Password string            `mapstructure:"password"`
    DBName   string            `mapstructure:"dbname"`
    Params   map[string]string `mapstructure:"params"`
    DSN      string            `mapstructure:"dsn"`

    MaxOpenConns           int `mapstructure:"max-open-conns"`
    MaxIdleConns           int `mapstructure:"max-idle-conns"`
    ConnMaxLifetimeSeconds int `mapstructure:"conn-max-lifetime-seconds"`
    ConnMaxIdleTimeSeconds int `mapstructure:"conn-max-idle-time-seconds"`
}
```

`Validate()` 改为：DSN 为空时才检查 Host/User/DBName。

`NewOptions()` 默认值：结构化字段 + `Params{"sslmode": "disable", "TimeZone": "Asia/Shanghai"}`。

### 3. [`infrastructure/persistent/postgres/db.go`](internal/resource/infrastructure/persistent/postgres/db.go)

添加 `buildDSN(cfg infradb.Config) string`，优先使用 `cfg.DSN`，否则从字段拼装：

```go
func buildDSN(cfg infradb.Config) string {
    if cfg.DSN != "" {
        return cfg.DSN
    }
    dsn := fmt.Sprintf("host=%s user=%s password=%s dbname=%s port=%d",
        cfg.Host, cfg.User, cfg.Password, cfg.DBName, cfg.Port)
    for k, v := range cfg.Params {
        dsn += fmt.Sprintf(" %s=%s", k, v)
    }
    return dsn
}
```

未来 `mysql/db.go` 也有自己的 `buildDSN`，拼 `user:pass@tcp(host:port)/db?k=v` 格式。

### 4. [`app.go`](internal/resource/app.go)

`dbConfigFromOptions` 更新为映射公共字段 + `Params`：

```go
func dbConfigFromOptions(o options.DatabaseOptions) infradb.Config {
    return infradb.Config{
        Driver: o.Driver, Host: o.Host, Port: o.Port,
        User: o.User, Password: o.Password, DBName: o.DBName,
        Params: o.Params, DSN: o.DSN,
        MaxOpenConns: o.MaxOpenConns, ...
    }
}
```

### 5. [`config/resource.yaml`](config/resource.yaml)

```yaml
database:
  driver: postgres
  host: 127.0.0.1
  port: 5432
  user: postgres
  password: postgres123
  dbname: resource
  params:
    sslmode: disable
    TimeZone: Asia/Shanghai
  max-open-conns: 50
  max-idle-conns: 10
  conn-max-lifetime-seconds: 1800
  conn-max-idle-time-seconds: 300
```

`run.go` / `server.go` 无需改动（已经接受 `infradb.Config`）。

## 切换到 MySQL 只需改 resource.yaml

```yaml
database:
  driver: mysql
  host: 127.0.0.1
  port: 3306
  user: root
  password: secret
  dbname: resource
  params:
    charset: utf8mb4
    parseTime: "True"
    loc: Local
```

Go 代码零改动。
